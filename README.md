# Prime-gap admissibility counting

A Lean/mathlib development of finite residue-coverage counts that arise in Hardy–Littlewood admissibility questions.

For a prime modulus `p` and tuple length `k`, the formalization studies residue walks generated by partial sums and counts the tuples whose visited residues fail to cover every class modulo `p`.

## Main formula

The source proves the finite inclusion–exclusion identity

\[
\operatorname{admissibleCount}(p,k)
= p^{k-1}
- \sum_{t\subseteq \operatorname{nonzeroRes}(p)}
(-1)^{|t|}(p-|t|)^{k-1}.
\]

This is an exact finite combinatorial statement about residue coverage.

## Exact special cases

The formal chain includes

\[
\operatorname{admissibleCount}(2,k)=1
\]

for all `k`, and for `k>=1`,

\[
\operatorname{admissibleCount}(3,k)=2^k-1.
\]

At the first-cover boundary `k=p`, the recorded exact values include

\[
\operatorname{admissibleCount}(3,3)=7,
\]
\[
\operatorname{admissibleCount}(5,5)=601,
\]
\[
\operatorname{admissibleCount}(7,7)=116929.
\]

Equivalently, the complementary cover counts are `2`, `24`, and `720`, matching `(p-1)!` for `p=3,5,7`.

The general identity

\[
\operatorname{coversCount}(p,p)=(p-1)!
\]

is the natural remaining boundary; the recovered source does not prove it.
